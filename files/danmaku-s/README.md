# 東方月砕異変 ― 素材の差し替え（config.js）

画像や音は、ゲームと同じフォルダに置いた `config.js` で指定します。ゲーム内に画像の設定画面はありません。

## 使い方

1. ゲームのHTMLをパソコンに保存します。
2. 同じフォルダに `config.js` を置きます。画像や音のファイルは、好きなフォルダに置いてください。
3. `config.js` に、HTMLからの相対パスを書きます。

```
tsukiakari.html
config.js
img/    reimu.png, boss01.png ...
audio/  field.mp3, shot.wav ...
```

* `config.js` は `.json` と同じ内容ですが、`<script>` として読み込むので、ファイルを直接開いても CORS に引っかかりません。
* パスが空、または未記載の項目は、内蔵の素材を使います。ファイルが見つからないときも内蔵に戻ります。
* 公開ページ（claude.ai 上）では外部ファイルを読み込めません。素材を差し替えるときは、HTMLを保存して開いてください。
* ブラウザの仕様で、BGMはタイトルを一度クリックしてから鳴ります。
* 設定画面の「素材」の下に、`config.js` を読み込めたかどうかが表示されます。

## chara（キャラクター画像）

|キー|内容|
|-|-|
|`reimu` / `marisa` / `kaguya`|立ち絵（会話に出る絵）|
|`reimu\_b` / `marisa\_b` / `kaguya\_b`|バトル絵（戦闘中の小さな絵）|
|`boss01`〜`boss20`|第1〜20章のボスの立ち絵|
|`boss01\_b`〜`boss20\_b`|第1〜20章のボスのバトル絵|
|好きな名前（例 `"チルノ"`）|カスタムステージで、その名前の話者の立ち絵|

* 立ち絵は縦長で背景が透明のPNGがおすすめです（例: 600×900px）。
* バトル絵は、顔や上半身が中心の正方形に近い画像がおすすめです。
* `\_b` を書かなかった場合のバトル絵は、内蔵の絵、または指定した立ち絵を上半身で切り抜いたものになります。

## audio（音）

### BGM（`audio.bgm`）

|キー|内容|
|-|-|
|`op`|オープニング（約40秒、1回再生）|
|`title`|タイトル画面|
|`field`|道中（全章・全ステージ共通）|
|`boss`|ボス戦（全章・全ステージ共通）|
|`ending`|ボス撃破後の会話（未指定なら道中の曲が続く）|
|`clear` / `over`|クリア画面／ゲームオーバー画面（1回だけ再生）|

章やステージごとに個別に指定するときは、次の名前を使います。指定がなければ上の共通BGMになります。

* 第N章: `field01`〜`field30`（道中）、`boss01`〜`boss20`（ボス戦）
* オリジナルシナリオ: `field\_os1`〜`field\_os3`、`boss\_os1`〜`boss\_os3`
* カスタムステージ（スロット1〜4）: `field\_c1`〜`field\_c4`、`boss\_c1`〜`boss\_c4`（エディタで一度開いて保存したステージに付きます）
* カスタムステージは、エディタの「設定」タブにある「道中BGM」「ボスBGM」にパスを書く方法でも指定できます。config.js の `bgm` に書いた名前も使えます。

### 効果音（`audio.se`）32種

|種類|キー|
|-|-|
|戦闘|`shot` `graze` `kill` `hit` `bomb` `nobomb`（ボム不足） `bosshit` `knife`|
|ボス・スペル|`boss` `spell` `phase`（通常攻撃を破った） `spellclear` `bossdown` `timeout` `stop` `resume`|
|アイテム|`item` `power` `point` `bombget` `life`|
|メニュー|`menu` `move` `cancel` `pause` `unpause` `start` `load` `save` `text`|
|結果|`clear` `over`|

`item` / `clear` / `menu` / `save` だけを書くと、同じ仲間の効果音（`power` `point` `bombget` `life`、`phase` `spellclear` `bossdown`、`pause` `unpause` `cancel` `move`、`load`）も同じ音になります。個別に書けば、そちらが優先されます。mp3、wav、ogg など、ブラウザで再生できる形式が使えます。

## オープニング（OP）

起動すると、まず「クリックかキー入力を待つ画面」が出て、そのあとにオープニング（約40秒）が流れます。クリック・キー・コントローラーのボタンでスキップできます。設定画面の「OP」で、起動時に再生するかどうかを選べて、「今すぐ見る」でいつでも見直せます。OPの曲は `audio.bgm` の `op` で差し替えられます。

## Config-sample.js（テスト用）

画像と音をファイルの中に埋め込んだサンプルです。`config.js` が無いときだけ、HTMLと同じフォルダの `Config-sample.js` を自動で読み込みます。立ち絵が「TEST」の箱になり、BGMと効果音が変わっていれば、読み込みは成功です。

## 8bit風の音（内蔵）

BGM4曲（`op` `title` `field` `boss`）と効果音16種を、8bit風で作成してHTMLに内蔵しています。`config.js` が無くても、そのまま鳴ります。同じ音のファイルは audio-8bit.zip に入っています。

|曲|内容|
|-|-|
|op|オープニング（約40秒）。砕ける瞬間・ボス紹介・ロゴの出現に合わせた構成|
|title|タイトル（BPM84、Aマイナー）|
|field|道中（BPM150、Dマイナー）|
|boss|ボス戦（BPM168、Aハーモニックマイナー）|

自分の音に変えるときは、`config.js` の `audio` で上書きできます。

## カスタムステージの立ち絵

エディタの「設定」タブで、話者名（ボス／霊夢／魔理沙／好きな名前）と画像を選ぶと、そのステージだけで使われます。立ち絵とバトル絵を選べます。ステージのJSONにも含まれるので、書き出して共有できます。

## 注意

画像の利用は、東方Project二次創作ガイドラインなど、元の権利者が定める条件の範囲で行ってください。



## 東方月塵録（全20章）

* 第1〜20章。第15章で月が戻り、第20章のクリアで物語が完結します（クリア後の画面に「全章クリア」と出ます）。

## 差分（バリエーション）画像

config.js の `chara` に、通常の絵の名前へ差分名を足して書きます。無い差分は、config に書いた通常の絵で表示されます。

|種類|名前|いつ使われるか|
|-|-|-|
|ボスのバトル絵|`boss18\_b\_a` 〜 `boss18\_b\_d`|技の順番（a=1つ目、b=2つ目、c=3つ目、d=4つ目）|
|霊夢・魔理沙のバトル絵|`reimu\_b\_a` / `marisa\_b\_a`|ボム中|
|同上|`reimu\_b\_b` / `marisa\_b\_b`|被弾後などの無敵中|
|立ち絵|`boss18\_a`、`reimu\_c` など|会話の行に `ボス@a: セリフ` と書いたとき|

立ち絵の差分名には `b` を使えません（`boss18\_b` はバトル絵の名前のため）。会話の差分は、カスタムステージのシナリオ欄で指定できます。

## 統計・設定

* タイトルの「統計」: プレイ時間、累計スコア、かすり、章ごとのベストスコア・クリアした難易度・ノーミス／ノーボム印などを表示します。
* 「設定」: 左のカテゴリ（操作・サウンド・画面・素材・データ・情報）で切り替えます。BGM／効果音の音量、画面フラッシュの軽減、揺れのオフ、FPS表示、データの初期化が使えます。

## 起動時の音声の読み込み

起動画面で、BGMと効果音の読み込みが終わるまで待ちます（最大15秒。6秒を過ぎると「タップでスキップ」が出ます）。



## シナリオエディターと scene.js

設定の左メニュー「シナリオ」から「シナリオエディターを開く」で、第1〜20章の会話を書き換えられます。

* 章ごとに、導入・道中・ボス前・決着後の4つを編集できます。編集はすぐゲームに反映され、このブラウザに保存されます。
* 書き方は、1行に1セリフで「話者: セリフ」です（話者は ボス／灯（プレイヤー）／ナレーション／好きな名前）。行の頭に \[霊] か \[魔] を付けると、そのキャラで遊ぶときだけ表示されます。「ボス@a: セリフ」で立ち絵の差分が使えます。
* 「会話プレビュー」で、霊夢・魔理沙のどちらの場合も確認できます（プレイ中のポーズ画面から開いたときはプレビューできません）。
* 「scene.js を書き出す」で、全20章のシナリオを scene.js として保存します。「コピー」で内容をクリップボードに、「取り込む」で書き出した scene.js をエディターに読み込めます。
* scene.js を index.html と同じフォルダに置くと、標準のシナリオを置き換えます。scene.js に書いていない章・項目は標準のままです。
* 優先順位は、標準 < scene.js < エディターで編集した内容 です。「標準に戻す」は、内蔵の標準シナリオに戻します。
* 同梱の scene.js は、標準シナリオをそのまま書き出した見本です。テキストエディターで直接書き換えてもかまいません。
