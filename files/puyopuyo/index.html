DUAL LOCK
ローカル対戦テトリス。1P〜4Pを切り替え可能。10×20フィールド、ライン消しで相手にお邪魔ブロックを送る。
1ライン消し → お邪魔 0段 / 2ライン → 1段 / 3ライン → 2段 / 4ライン(テトリス) → 4段。T-Spinはさらに大きなお邪魔を送れます。
2P以上では各プレイヤーの画面が現在のブロックを中心に上下スクロール(ON/OFF切替可)。移動2つ・低速落下・高速落下(通常の約8倍速)・ホールド・回転の6キー構成です。
回転はtetris.wiki記載のSRS(Super Rotation System)壁キック準拠、接地後0.5秒のロック遅延あり(移動/回転で最大15回リセット)。全員同時スタート。
