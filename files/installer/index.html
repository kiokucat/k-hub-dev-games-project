K-HUB Desktop

ゲームをダウンロードして、カセットのように並べて遊べるデスクトップランチャー。一度入れれば、ネットがなくても起動できます。

主な機能

シンプルで軽く、安全に遊べることを大事にしています。

ゲームハブ

配信者が公開したゲームが一覧に並びます。ボタン一つでダウンロードから展開まで自動で完了。進捗は％で表示されます。

3Dカセットのライブラリ

ダウンロード済みのゲームをカセットで表示。←→で選んで「プレイ」を押すと画面が点灯し、そのままゲームが起動します。

完全オフライン起動

導入済みのゲームはネットなしで遊べます。ゲームごとに保存先もセーブデータも分離されます。

安全なアップデート

更新は一時フォルダに展開→検証→入れ替えの順。失敗しても元のゲームが残るので、遊べなくなりません。

状態がひと目で分かる

「最新」「更新あり」「通信失敗」「取得失敗」を区別して表示。サイドバーには更新件数も出ます。

演出とやさしさ

カセットを差し込む起動演出つき（クリックでスキップ可）。OSの「視覚効果を減らす」設定ならアニメは省略されます。

使い方

3ステップで遊べます。

  1. ゲームハブでダウンロード気になるゲームを選んで「ダウンロード」を押すだけ。
  2. ライブラリでカセットを選ぶ←→ボタン（またはキーボードの←→）で中央に合わせます。
  3. 「▶ プレイ」で起動以後はネットがなくても遊べます。更新があれば「アップデート」が出ます。

安心して使える設計

ゲームは専用の隔離環境で動き、PCの他の場所には触れません。

隔離された実行環境

Electronのsandbox・contextIsolationを有効化し、ゲームは専用プロトコルで配信。許可なしの権限要求はすべて拒否します。

ZIPを事前に検証

不正なパスや展開先の外へ出るファイルは、書き込む前にすべて拒否します。

外部リンクは限定

外部URLとして開けるのは GitHub の公式ドメインのみです。

動作環境・技術

低スペックのPCでも軽快に動くよう、フレームワークなしで作られています。

ダウンロード

Windows 10 / 11 専用です（macOS・Linuxには対応していません）。

インストーラー版インストール先を選んで導入。スタートメニューに登録されます。K-HUB Desktop-Setup-0.1.0.exe ポータブル版インストール不要。好きなフォルダやUSBメモリから起動できます。K-HUB Desktop-0.1.0-portable.exe

初回起動時はSmartScreenの警告が出ることがあります（コード署名なしのため）。
