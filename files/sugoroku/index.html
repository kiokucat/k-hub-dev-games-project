    HELP 遊び方

    基本: サイコロを振ってマスを進み、コインを集めて勝負！自分のターンは「サイコロ / カード / マップ」から選べる。
    移動: 強制移動は自動で進む（分岐は選択）、自由移動はWASD/矢印キーで1マスずつ進める（来た道も引き返せる）。
    マス: ■青=ルーレットでコイン獲得 / ■赤=ルーレットでコイン減少 / ■黄=カードを1枚獲得(所持上限まで) / ■紫=カードショップ(売買) / □無色=何もない…のかも / ◎ゴール=止まると順位確定(すごろくルール)
    桃鉄ルール: 無色マスのどれか1つがランダムで「隠れゴール」。誰かが見つけるとボーナス+3000で即終了。移動は必ず自由移動。
    カード: 移動・妨害・交換・倍率など全23種。ターン開始時に「カード」から使用（対象ありは数字キーで選択可）。
    決着: 全員ゴール or 制限ターン終了時、コインの多い順でランキング。
